# Легенды Средневековья: Долг души

Аниме-новелла в фэнтези-мире для Telegram (Mini App). Бесплатно, без рекламы и без покупок.

Ты тонешь, спасая ребёнка, и просыпаешься в чужом мире. Белая богиня зимы вернула тебе жизнь в долг. Дальше гильдия бродяг, напарница, лисица Искра, Церковь Солнца и её Солнечный Трон.

## Как играть
- Нажимай на экран, чтобы листать реплики.
- В выборах ты решаешь, что скажет твой герой. Выборы меняют диалоги и отношения, сам сюжет идёт одной дорогой.
- В начале богиня Юки дарит герою магию, напарницей становится Лина, позже присоединяется Кайра. Имя героя можно поменять в настройках.
- В арке 7 выбираешь, с кем проведёшь ночь перед Мглой. В финале сам выбираешь концовку (их четыре, одна только для пути Ильвенн).
- Игра сама сохраняется после каждой реплики. В меню есть три ручных слота, журнал и отношения.

## Файлы
- `index.html`, `css/vn.css`, `js/engine.js` — интерфейс и движок новеллы, без сборки и зависимостей.
- `story/` — весь текст сюжета в Markdown (`00-bible.md` — описание мира и персонажей).
- `js/story-data.js` — сюжет для движка. Собирается командой `python3 tools/build_story.py` из `story/*.md`.
- `js/art.js` — список готовых картинок в `art/`. Если картинки нет, игра показывает цветной фон.
- `docs/TELEGRAM_SETUP.md` — как подключить игру к боту в Telegram.

## Запуск локально
`python3 -m http.server` в папке проекта и открыть http://localhost:8000. Прогресс хранится в localStorage браузера.
