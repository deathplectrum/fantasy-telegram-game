# Легенды Средневековья

Фэнтези-игра в виде Telegram Mini App. Рыцари и маги, город-хаб, бой в реальном времени, уровни до 100.
Бесплатно, без рекламы и без платных покупок.

## Что уже есть
- Пролог с белой богиней, выбор пути (Меч или Магия, можно сменить 3 раза), имя героя.
- Сюжет «Долг души»: 8 глав сценками, лиса Искра, «настоящий герой» сэр Эдрик, три концовки.
- Главный экран: стеклянные кнопки поверх пиксельного фона, мощь, Гильдия/Задания/Награды, док снизу.
- Снаряжение: оружие в центре, 5 слотов и артефакт, усиление за золото.
- Бой в реальном времени: атака, приём с перезарядкой, блок (идеальный блок на «!!»), две фазы у боссов, без ваншотов.
- Пять зон (уровни 1–100), пять боссов с артефактами, героические боссы после концовки.
- Ежедневные задания (2 лёгких + 1 тяжёлое), награды за вход 7 дней, 13 достижений, случайные события.
- Зелья только до боя, максимум 2. Смерть без потери золота; 15% риск потерять улучшения предмета против босса на 5+ уровней сильнее.
- Обучение советами Марты.

## Файлы
- `index.html`, `style.css`, `game.js`, `story.js` — сама игра, без сборки и зависимостей. `story.js` — весь текст сюжета.
- `assets/` — графика из открытых наборов CC0, список источников в `assets/CREDITS.md`.
- `docs/TELEGRAM_SETUP.md` — как подключить игру к боту в Telegram по шагам.
- `docs/IMAGE_PROMPTS.md` — промпты для нейросети, чтобы сделать картинки в одном стиле.

## Запуск локально
Открой `index.html` в браузере. Прогресс сохраняется в localStorage браузера.
