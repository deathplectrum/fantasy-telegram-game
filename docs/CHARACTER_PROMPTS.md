# Промпты для главного фона и моделек персонажей

Стиль: мягкий аниме-гача стиль (как в Genshin Impact или Gacha Life, без реализма), яркие чистые цвета, большие выразительные глаза, мягкое освещение. Чтобы было похоже на игру, добавь в каждый промпт «video game key art, mobile game UI background». Без текста и без водяных знаков.

Общий хвост для всех промптов:
> anime gacha style, clean cel shading, vibrant colors, mobile game key art, no text, no watermark, no logo

## 1. Главный экран (фон)

Сверху небо с облаками, снизу трава и один-два цветочка по бокам. Персонаж стоит по центру, поэтому место под него оставляем свободным.

> anime gacha game background, upper part bright blue sky with soft fluffy clouds, lower part lush green grass with one or two small flowers on the left and right edges, empty clean center for a character, soft sunlight, 9:16 portrait, + общий хвост

Отдельно сделай версию **без травы и цветов**, только небо с облаками, если понадобится для шапки экрана.

## Как пользоваться

1. Сгенерируй персонажей с **прозрачным фоном** или на ровном сером фоне, чтобы легко вырезать.
2. Для каждого ранга держи одинаковые позу и размер, чтобы персонажи менялись на экране без скачков.
3. Имена файлов: `hero-sword-boy-1.png`, `hero-sword-girl-1.png`, `hero-magic-girl-4.png`. Так я сам подставлю нужный по фракции и уровню.
