Стиль для всех картинок: рисованная акварель с тёплыми приглушёнными цветами, тонкие контуры, без текста и без водяных знаков. Формат квадрат 1:1 для иконок и 16:9 для сцен.

Общий хвост для всех промптов:
> hand-painted watercolor fantasy illustration, warm muted palette, soft ink outlines, medieval fantasy, no text, no watermark
